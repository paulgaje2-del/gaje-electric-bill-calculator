# 💡 Electric Bill Calculator

A simple and clean web application to calculate your monthly electric bill based on power consumption and cost per kilowatt-hour.

## 🎯 Features

- **Calculator**: Enter your power consumption (kWh) and cost per kWh to calculate your bill
- **Dashboard**: Quick overview with recent calculations and a mini calculator
- **Results**: View all saved calculations in a table format
- **Profiles & Authentication**: Login/register and manage your profile
- **Light Theme**: Modern, clean UI with responsive design
- **Local Storage**: All calculations saved in your browser

## 📂 Project Structure

```
├── index.html          # Home page
├── calculator.html     # Main calculator page
├── dashboard.html      # Dashboard with recent calculations
├── result.html         # View all saved results

├── login.html          # Login page
```

## 🚀 Quick Start

1. **Clone the repository**
   ```bash
   git clone https://github.com/paulgaje2-del/gaje-electric-bill-calculator.git
   cd gaje-electric-bill-calculator
   ```

2. **Open in browser**
   - Double-click `index.html` or open it in your web browser
   - Or use a local server (Python, Node.js, etc.)

3. **Start calculating**
   - Navigate to the **CALCULATOR** page
   - Enter month, power consumption (kWh), and cost per kWh
   - Click **Calculate** to see your bill
   - Your results are automatically saved

## 🎨 Design

- **Light Theme**: Clean white cards with blue accents
- **Bootstrap 5**: Responsive grid layout
- **CSS Variables**: Easy to customize colors and spacing
- **Mobile Friendly**: Works on desktop, tablet, and mobile devices

## 💾 Data Storage

All calculations are saved locally in your browser using `localStorage`. No server or database required.

- View saved calculations on the **RESULT** page
- Access recent calculations on the **DASHBOARD** page
- Clear all data with the "Clear All" button on the results page
