# Electric Bill Calculator (copied from Makenshiii/Ngalis-electric-bill-calculator)

This workspace contains the HTML/CSS/JS files for a simple electric bill calculator web app.

Required files present:
- `index.html`
- `calculator.html`
- `dashboard.html`
- `login.html`
- `register.html`
- `profile.html`
- `script.js`
- `database.js`
- `style.css`

Background image note:
- The project expects a background image file named `bg-calcu.jpg` at the project root.
- To download the original `bg-calcu.jpg` from the upstream repository, run this PowerShell command in the project folder:

```powershell
cd "c:/Users/Paupau/Desktop/gaje-electric-bill-calculator";
Invoke-WebRequest -Uri "https://raw.githubusercontent.com/Makenshiii/Ngalis-electric-bill-calculator/main/bg-calcu.jpg" -OutFile "bg-calcu.jpg"
```

After downloading the image you can open `index.html` (or other pages) in a browser.
